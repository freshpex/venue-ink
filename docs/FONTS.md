# Locally hosted fonts

Downloaded November 2, 2026 from the Google Fonts CSS service, selecting Latin WOFF2 subsets. Fonts are served locally with swap behavior; the primary heading and body faces are preloaded. The frontend does not require runtime requests to Google Fonts.

- Barlow Condensed 500, 600 and 700 by the Barlow Project Authors. [Project](https://github.com/jpt/barlow). License: `public/fonts/barlowcondensed-OFL.txt`.
- DM Sans variable 400–700 by the DM Sans Project Authors. [Project](https://github.com/googlefonts/dm-fonts). License: `public/fonts/dmsans-OFL.txt`.

Both use the SIL Open Font License. Copyright and full license notices are distributed with the font files. The files were obtained from `fonts.gstatic.com` through the official Google Fonts CSS endpoint; licenses were retrieved from the Google Fonts repository via its jsDelivr mirror.
